Установка плагина ejudge для CLion (Windows, через PowerShell)

1. Закройте CLion.

2. Откройте PowerShell: нажмите клавишу Win, наберите PowerShell, нажмите Enter.

3. Вставьте в окно PowerShell эту команду и нажмите Enter:

Invoke-WebRequest https://github.com/vmaiorov-collab/ejudge-clion/releases/latest/download/ejudge-clion.zip -OutFile $env:TEMP\ejudge-clion.zip; Expand-Archive -Force $env:TEMP\ejudge-clion.zip "$env:APPDATA\JetBrains\CLion2026.2\plugins"

4. Запустите CLion: плагин появится в Settings → Plugins → Installed.

Если у вас другая версия CLion, замените CLion2026.2 на имя своей папки: посмотреть можно командой dir "$env:APPDATA\JetBrains".
