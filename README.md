# Конспекты лекций — Олимпиадное программирование

Подробные, самостоятельные конспекты лекций курса **Яндекс Кружка** по олимпиадному программированию. Каждый конспект — автономный HTML-файл, который можно читать офлайн прямо в браузере.

## Сайт

**[vmaiorov-collab.github.io/conspectus](https://vmaiorov-collab.github.io/conspectus/)** — навигатор: выбери параллель, затем лекцию.

## Как читать

1. Открой [сайт](https://vmaiorov-collab.github.io/conspectus/) или `index.html` локально.
2. Выбери параллель.
3. Открой нужную лекцию — конспект откроется в новой вкладке.

Файлы работают без интернета: стили, скрипты и шрифты формул (KaTeX) встроены как data-URI, так что вёрстка и формулы не «плывут» офлайн. Удобно читать с телефона и печатать.

На каждой странице есть переключатель оформления — «книга» (редакторская вёрстка, шрифт PT Serif) и «бумага» (прежний вид); выбор запоминается в `localStorage` (`conspectusLook`). Отдельно переключается тёмная/светлая тема (`conspectusTheme`). PT Serif запрашивается как веб-шрифт (не встроен в HTML) — если его нет в системе и нет интернета, «книга» тихо откатывается на Georgia/Times New Roman.

### Темы по занятиям

- **Математика** — асимптотики, алгоритм Евклида и расширенный Евклид, обратный элемент, функция Эйлера, быстрое возведение в степень и modint, КТО (CRT), гармонические суммы и оценки делителей, дискретный логарифм (baby-step giant-step), первообразный корень, включения-исключения и беспорядки, Миллер—Рабин, ро-алгоритм Полларда, суммы по полу и оценки сложности.
- **Оптимизации DP** — переливайка (small-to-large), рюкзак на дереве, Convex Hull Trick, лямбда-оптимизация, оптимизация Кнута, divide & conquer для ДП, оффлайн-связность, матрицы, slope trick.
- **Корневые эвристики** — блочная декомпозиция, тяжёлые/лёгкие вершины, корневая по запросам, алгоритм Мо (дерево, откаты, 3D).
- **Структуры данных 1** — дерево отрезков (в т.ч. снизу и неявное), дерево Фенвика, массовые операции, сжатие координат, сканирующая прямая.
- **Графы 1** — хранение графов, степени и суммы, времена входа/выхода и вложенность интервалов, топологическая сортировка, компоненты связности (в т. ч. Косарайю и конденсация), ДП на деревьях (высота, диаметр, независимое множество) и на DAG.
- **Строки 1** — префикс-функция и КМП, Z-функция, бор и бинарный бор.
- **C++** — сложность, типы и переполнение, структуры и компараторы, вектор/стек/очередь/дек, set/map/priority_queue, алгоритмы STL, стресс-тестирование.
- **Поиски** — бинарный поиск по массиву и по ответу, вещественные числа, бинпоиск по производной, тернарный поиск.
- **Вводная лекция** — устройство курса, правила, система оценивания, олимпиадный ландшафт.
- **Оценка сложности и сортировки** — O-нотация, квадратичные сортировки, подсчётом, слиянием, std::sort.

## Иллюстрации

Все схемы, деревья, графики и анимации встроены как **чистый инлайн-SVG в стиле 3Blue1Brown** — без внешних библиотек (никакого manim/mermaid) и без терминальной ASCII-псевдографики. Поэтому каждый конспект остаётся одним автономным файлом.

- Иллюстрация — это `<figure class="viz">` с `<svg>` и подписью `<figcaption>`.
- Визуальный «кадр»: тёмная панель, чистая геометрия, светящиеся линии, крупные подписи.
- Псевдокод и программы — обычные блоки `<pre><code>`, а не рисунки.
- Векторный SVG масштабируется (`viewBox`, `width:100%`) и корректно печатается.
- Алгоритмы можно «проигрывать»: сортировки (пузырёк, выбором, вставками, подсчётом, слиянием), бинарный поиск и slope trick — интерактивные, с ползунком и кнопкой ▶.

## Для тех, кто дорабатывает репозиторий

### Структура файлов

```
conspectus/
├── index.html                  # навигатор по параллелям и лекциям
├── parallel-a/                 # конспекты параллели A
├── parallel-ap/                # конспекты параллели A'
├── parallel-b/                 # конспекты параллели B
├── parallel-bp/                # конспекты параллели B'
├── parallel-c/                 # конспекты параллели C
├── figures/                    # python-генераторы инлайн-SVG иллюстраций
├── scripts/                    # локальные разовые скрипты (idea-bot, stats-bot, paper-style)
└── bots-worker/                # Cloudflare Worker: telegram-боты на вебхуках (прод)
```

### Telegram-боты

Два бота на одном Cloudflare Worker (`bots-worker/`, деплой через `wrangler`, подробности — в `bots-worker/README.md`):

- **idea-bot** (`@conspectus_csbot`) — пересылает идеи и вопросы читателей владельцу репозитория.
- **stats-bot** — отвечает на `/stats`, `/today`, `/top`, `/parallels`, читая статистику из Cloudflare Web Analytics.

Локальные версии тех же ботов (`scripts/idea-bot.py`, `scripts/stats-bot.py`) используются только для разовой отладки — в проде работает воркер.

### Статистика

Посещения считают одновременно GoatCounter (без куки, [публичная статистика за месяц](https://vmaiorov.goatcounter.com/)) и Cloudflare Web Analytics (приватная, читается ботом `stats-bot`).
